# Lottery System - 抽奖系统

一个功能完善、视觉精美的企业级抽奖系统，支持多奖池、多奖项等级、权重抽奖等功能。

## 🎉 Demo 展示

![抽奖系统 Demo](./demo.png)

## 功能特性

### 🎰 核心抽奖功能
- **多奖池管理**：支持创建和管理多个独立的抽奖池
- **多奖项等级**：支持一、二、三等奖等多个奖项等级
- **权重抽奖**：支持为参与者设置权重，提高中奖概率
- **批量抽奖**：支持一次抽取多位幸运儿
- **中奖记录**：自动记录所有中奖信息，支持查看历史记录

### 📊 数据管理
- **Excel导入**：支持通过Excel批量导入参与者和奖品
- **参与者管理**：支持添加、编辑、删除参与者信息
- **奖品管理**：支持配置奖品名称、图片、数量等信息
- **本地存储**：所有数据自动保存到本地浏览器存储中

### 🎨 视觉效果
- **3D粒子背景**：炫酷的3D粒子动画背景
- **抽奖动画**：流畅的滚动动画和中奖展示
- **礼花效果**：中奖时自动触发礼花庆祝
- **自定义主题**：支持自定义Logo、背景、标题等UI元素

### 🔊 音效系统
- **背景音乐**：抽奖全程背景音乐
- **滚动音效**：抽奖过程中的滚动音效
- **中奖音效**：中奖时的庆祝音效
- **自定义音效**：支持上传自定义音频文件

## 技术栈

- **框架**：React 18
- **语言**：TypeScript
- **构建工具**：Webpack 5
- **样式**：Tailwind CSS
- **状态管理**：Zustand
- **动画**：Framer Motion
- **3D**：Three.js + React Three Fiber
- **UI组件**：Radix UI + Lucide Icons
- **其他**：Canvas Confetti、XLSX

## 使用说明

### 1. 配置奖池
- 点击管理员面板（通常位于界面角落）
- 在"奖池管理"中创建或编辑奖池
- 每个奖池可以独立配置参与者和奖品

### 2. 导入参与者
- 在管理员面板中进入"参与者管理"
- 点击"导入Excel"按钮上传参与者列表
- 支持的列名：花名/姓名、业务线/部门、主管、次数/权重

### 3. 配置奖品
- 在管理员面板中进入"奖品管理"
- 添加或导入奖品信息
- 设置奖品等级、名称、图片和数量

### 4. 开始抽奖
- 选择要使用的奖池
- 选择奖项等级
- 设置抽取数量
- 点击"开始抽奖"按钮
- 滚动结束后点击"停止抽奖"查看结果

### 5. 自定义配置
- 在管理员面板的"设置"中可以：
  - 上传自定义Logo
  - 设置背景图片
  - 修改标题和标语
  - 配置音效
